# AI 模型选择与成本优化指南

## 目标

每个 v0.2 阶段完成后，使用最合适的模型进行专项优化，在质量和成本间取得平衡。

## 可用模型与成本

| 模型 | 输入/1M tokens | 输出/1M tokens | 中文质量 | 代码能力 |
|------|:------------:|:-------------:|:-------:|:-------:|
| DeepSeek V4 Flash | 免费 | 免费 | 好 | 强 |
| Kimi K2.6 | $0.95 | $4.00 | 强 | 中 |
| GPT-5.5 | $5.00 | $30.00 | 强 | 强 |

## 各模型使用场景总结

### DeepSeek V4 Flash（免费 — 日常主力）

全天候免费使用，适合：
- 代码生成与检查
- JSON 数据验证
- 逻辑正确性审核
- 节点路径匹配验证
- 禁词批量扫描
- 所有非中文文本任务

### Kimi K2.6（$0.95/$4.00 — 文本专项）

成本可控，适合：
- 中文叙事文本逐条评审
- 系统口吻一致性检查
- 选项文本长度与风格检查
- 禁词中文语境检查
- 文案打磨与优化

### GPT-5.5（$5.00/$30.00 — 阶段交付前才用）

最贵，适合：
- 每阶段最终一次全栈审核
- 设计方向与 UI 布局评审
- 综合体验质量判断
- 架构方案决策

## 成本估算

按每个阶段约 50K tokens 输入、10K tokens 输出的典型使用量估算：

| 模型 | 一次优化成本 |
|------|:----------:|
| DeepSeek V4 | $0（免费） |
| Kimi K2.6 | ~$0.09 |
| GPT-5.5 | ~$0.55 |

整个 v0.2 六个阶段的总 AI 优化成本预计可控在 **$5 以内**。

## 核心理念

1. **免费模型优先**：DeepSeek V4 能做的事不花冤枉钱
2. **中文用 Kimi**：中文文本评审性价比远高于 GPT-5.5
3. **GPT-5.5 只在交付前**：每阶段只在最后综合审核时用一次
4. **不要混合跑同一任务**：同一个审核任务不要用两个模型重复跑
