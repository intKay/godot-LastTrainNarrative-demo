# 《叙事校准程序 / 末班车站》v0.1 一分钟垂直切片

## 切片目标

在开发完整 v0.1 前，先做一个 1 分钟可玩的垂直切片。

切片只验证三件事：

1. 选择是否有反馈
2. 车站是否有氛围
3. 文本是否有张力

如果这一分钟没有感觉，不要扩展到完整 10 分钟流程，先调整文案、反馈和 UI 节奏。

## 切片范围

包含：

1. 叙事校准程序界面
2. 一个校准问题
3. 四个选项
4. 生成末班车站
5. 车站初始文本
6. 公告牌点击调查
7. 第一轮主线选择
8. 选择后的广播灯变化
9. 公告牌出现选择残影

不包含：

1. 完整三问
2. 完整五轮
3. 三个结局
4. 真实 AI API
5. 音乐系统
6. 复杂美术

## 切片流程

### Step 1：显示叙事校准程序

界面显示：

```text
叙事校准程序
请根据直觉完成以下选择。
系统将根据你的回答生成一段短篇体验。
```

### Step 2：显示第一个校准问题

问题方向：

```text
请选择故事的第一个锚点：
A. 一盏整夜没有熄灭的灯
B. 一扇始终没有打开的门
C. 一段无人回应的广播
D. 一张写错日期的车票
```

玩家点击任意选项后，记录一个初始 hint。

### Step 3：生成车站

系统显示：

```text
校准完成。
正在生成场景……
场景确认：末班车站。
```

然后切换到车站界面。

### Step 4：车站初始文本

示例方向：

```text
你站在一座空车站里。
公告牌亮着，广播没有声音。
时钟显示 23:47。
```

注意：最终文本应更有张力，但此处先作为结构占位。

### Step 5：点击公告牌

玩家点击公告牌。

公告牌调查文本根据第一问选择出现轻微差异。

如果玩家选择“灯”：

```text
公告牌显示：末班车即将进站。
下一行短暂闪了一下：
灯光参数已载入。
```

如果玩家选择“门”：

```text
公告牌显示：末班车即将进站。
下一行短暂闪了一下：
出口状态已载入。
```

目标：让玩家感到“刚才的选择被带入了车站”。

### Step 6：第一轮主线选项

显示 3～4 个选项。

示例方向：

```text
A. 询问广播这里是哪一站
B. 查看出口是否能打开
C. 继续等待末班车
D. 保持沉默，观察公告牌
```

对应状态变化：

- A：doubt +1，anomaly +1
- B：control +1
- C：obedience +1
- D：doubt +1

### Step 7：选择后的广播灯变化

如果玩家选择 A：

```text
广播灯亮了一下，又熄灭。
半秒后，它用和你相同的语气问：
“你希望这里是哪一站？”
```

如果玩家选择 B：

```text
出口指示灯亮起。
屏幕显示：离站许可尚未生成。
```

如果玩家选择 C：

```text
广播终于响起。
“请继续等待。故事正在保持稳定。”
```

如果玩家选择 D：

```text
公告牌刷新了一次。
没有车次，只有一行字：
观察行为已记录。
```

### Step 8：公告牌出现选择残影

玩家再次点击公告牌，看到：

```text
公告牌显示：23:47  末班车
目的地：校准中
上一行为：{玩家刚才的选择标签}
```

切片到此结束。

## 切片验收标准

这个 1 分钟切片完成后，需要回答：

1. 玩家是否能理解自己完成了一次选择？
2. 选择后是否有明确反馈？
3. 车站是否和校准问题发生了联系？
4. 公告牌变化是否让人感到不安或好奇？
5. 文本是否太直白？
6. 文本是否太平？
7. Godot 实现是否简单？

## 切片实现优先级

先做功能，不做美术。

优先级：

1. 文本显示
2. 按钮点击
3. 状态记录
4. 公告牌调查
5. 广播灯颜色变化
6. 简单音效
7. 简单视觉美化

不要在切片阶段做完整 UI 设计、复杂动画和大量背景图。
