## 结局文案改了什么

### 顺从结局

行数：7→7

**新意象**：
- "你上车后，车厢灯光逐排熄灭。" — 取代原来的"车门打开时，你没有看见驾驶员"
- "座位前方亮起一行字：你的等待记录已保存。" — 取代"你上车后，座位前方亮起一行字："
- "下一次校准将从这里开始。" — 取代"下一次校准将从你的等待记录开始。"

删去"广播说：故事已保持稳定。"，让收束更安静。

### 怀疑结局

行数：7→8

**新意象**：
- "问题列表比任何一次广播都长。" — 插在"它只显示你的问题"和"出口门"之间，强化对比感

其余保留原有框架。

### 控制结局

行数：7→8

**新意象**：
- "风从站内吹向站外。" — 插在"出口门打开一条缝"和"广播说"之间，增加空间倒错感

删去原"出口门打开一条缝"后的直接跳转，用意象过渡后再出广播。

## 主线文本改了什么

`station_round_3.visible_text` 第三行：

```
改前：出口指示牌第一次显示了你的选择记录。
改后：出口指示牌亮起。上面记录着你的每一次选择。
```

措辞更主动、揭示感更强（"第一次"→"亮起"，"你的选择记录"→"你的每一次选择"）。
