# 《叙事校准程序 / 末班车站》v0.1 开发任务清单

## 阶段 0：Godot 最小练习

目标：建立本项目所需的最低 Godot 心智模型。

任务：

1. 创建 Godot 4.x 项目
2. 创建一个 Control 根节点
3. 添加 Label 显示文本
4. 添加 4 个 Button 作为选项
5. 点击 Button 后更新 Label 文本
6. 添加变量 doubt，并在点击按钮时 doubt += 1
7. 添加一个“公告牌”按钮
8. 点击公告牌后显示调查文本

验收：

- 能运行
- 点击按钮有反馈
- 状态能变化

## 阶段 1：一分钟垂直切片

目标：验证核心体验。

任务：

1. 创建 calibration_screen.tscn
2. 实现一个校准问题
3. 创建 station_scene.tscn
4. 从校准界面切换到车站界面
5. 实现公告牌点击调查
6. 实现第一轮主线选项
7. 实现选项点击后的状态变化
8. 实现广播灯视觉变化
9. 实现公告牌显示选择残影
10. 加入最基础点击音效

验收：

- 玩家能完成 1 分钟流程
- 选择后至少一个车站元素变化
- 公告牌能体现玩家选择被记录
- 文本节奏不拖


## 优先级原则

优先做：

1. 选择反馈
2. 文本张力
3. 状态系统
4. 车站元素变化

暂时不做：

1. 真实 AI
2. 复杂美术
3. 自由输入
4. 角色移动
5. 多 NPC
6. 背包支线
7. 动态音乐
