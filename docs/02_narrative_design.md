# 《叙事校准程序 / 末班车站》v0.1 叙事设计与文本规范

## 叙事主题

这个游戏的主题不是“你被游戏测试了”这么简单，而是：

> 系统通过你反复做出的选择，看见了你如何理解故事、控制故事、逃离故事或顺从故事。

玩家最后应该感到的不是“被耍了”，而是“系统描述了我某种真实的选择方式”。

## 叙事结构

整体结构：

1. 玩家进入叙事校准程序
2. 玩家以为自己在选择故事生成参数
3. 系统生成末班车站
4. 车站根据玩家选择逐渐变化
5. 系统开始泄露选择记录
6. 玩家尝试测试或反抗系统
7. 系统给出最终判断

## 文本最高原则

文本不是装饰，而是交互反馈。

每句话最好承担以下至少一种功能：

- 反馈玩家刚才的选择
- 提供新信息
- 推进认知升级
- 暗示系统正在记录玩家
- 引导玩家点击下一步
- 误导或延迟暴露真相
- 改变玩家对场景的理解

如果一句话不提供信息、不回应选择、不改变理解、不推动下一步，就删掉。

## 文本风格

关键词：

- 短
- 冷
- 准
- 有信息量
- 克制
- 系统化
- 轻微刺痛感

适合的句子：

```text
广播停顿了半秒。
它重复了你刚才选择的词。
```

```text
公告牌刷新。
目的地一栏没有站名，只有你的上一个选择。
```

```text
出口没有上锁。
屏幕显示：离站许可尚未生成。
```

不适合的句子：

```text
广播在黑暗中微微颤抖，像一只迷失在夜色里的鸟，试图呼唤你回到命运的轨迹。
```

原因：过度文艺、信息密度低、和系统 UI 叙事不匹配。

## 禁止事项

1. 不要大段解释世界观
2. 不要直接说“其实你被测试了”
3. 不要把 meta 反转写成作者炫技
4. 不要让系统用长篇台词说教
5. 不要过度诗化
6. 不要用鬼怪、血腥、惊吓替代系统异常
7. 不要让玩家觉得选择只是装饰

## 开场三问方向

开场三问不是正式心理测试，而是故事校准。

三问分别承担：

1. 故事锚点
2. 注意细节
3. 偏离时的倾向

三问文案要求：

- 表面像故事选择
- 底层记录状态
- 不直接暴露人格标签
- 不过度文艺
- 能被系统解释为车站生成素材

示例方向：

```text
请选择故事的第一个锚点：
A. 一盏整夜没有熄灭的灯
B. 一扇始终没有打开的门
C. 一段无人回应的广播
D. 一张写错日期的车票
```

注意：此处为方向示例，不是最终文本。


## 文本验收问题

每段文本写完后，问：

1. 它有没有告诉玩家新信息？
2. 它有没有回应玩家刚才的选择？
3. 它有没有改变玩家对系统的理解？
4. 它有没有让玩家想点下一步？

如果四个答案都是“没有”，就删掉或重写。
