# 《叙事校准程序 / 末班车站》v0.1 UI / 美术 / 音频规范

## 总体视觉方向

冷淡系统 UI + 低饱和夜间车站 + 轻微故障感。

目标不是“画得好”，而是：

1. 风格统一
2. 信息清楚
3. 情绪准确
4. 制作成本低

## UI 风格

开场“叙事校准程序”应像一个冷淡的内部系统，而不是花哨游戏菜单。

车站界面应像一个被系统生成出来的叙事空间，而不是完整真实场景。

## 色彩原则

建议主色不超过 4 个：

1. 背景深色：黑 / 深灰 / 灰蓝
2. 正文浅色：浅灰 / 灰白
3. 交互高亮色：冷蓝 / 暗绿
4. 异常警告色：低饱和红 / 橙

避免：

- 高饱和霓虹
- 大量渐变
- 花哨 UI 边框
- 颜色过多

## 字体原则

1. 全项目尽量只用一种中文可读字体
2. 标题和正文只通过字号、字重区分
3. 不混用多种风格字体
4. 文本必须清晰易读

## 布局原则

推荐布局：

```text
顶部：系统名 / 当前阶段 / 时间
中部：车站视觉区域
中部元素：公告牌、时钟、广播灯、出口门
下方：叙事文本框
最下方：A/B/C/D 选项按钮
```

原则：

1. 留白足够
2. 不把屏幕塞满
3. 玩家一眼知道哪里是文本、哪里是选项、哪里可以调查
4. 所有交互元素要有悬停 / 点击反馈

## 动效原则

动效少而准。

v0.1 可做：

1. 按钮悬停变色
2. 广播灯闪烁
3. 公告牌轻微刷新
4. 文本打字机效果
5. 异常时短暂抖动

注意：

打字机效果必须可以跳过。  
不要让玩家长时间等文字出现。

## 美术策略

第一阶段：纯 Godot UI 占位。  
第二阶段：统一颜色、字体、间距。  
第三阶段：补低饱和车站背景。  
第四阶段：加轻微故障层和音效。

不要一开始就用大量 AI 图拼贴。AI 图容易风格不统一。

如果使用 AI 图，只建议生成：

1. 夜间车站背景
2. 公告牌纹理
3. 低饱和环境图

不建议 v0.1 生成复杂角色立绘。

## 音频方向

不要使用强旋律 BGM。玩家需要阅读文本，旋律太强会干扰阅读。

v0.1 需要：

1. 按钮点击音
2. 选项确认音
3. 广播电流声
4. 公告牌跳字声
5. 异常出现的短促低频音
6. 一条低频环境循环音

后续可扩展三层音乐：

1. 正常层
2. 异常层
3. 系统暴露层

v0.1 不做复杂动态音乐系统。

## 禁止事项

1. 不使用风格不统一的大量素材
2. 不使用复杂角色立绘
3. 不使用鬼怪、血腥、惊吓画面
4. 不使用过强旋律 BGM
5. 不做花哨转场
6. 不让 UI 信息过载
7. 不让美术追求拖慢核心玩法验证

## 视觉验收标准

一个画面是否可用，问：

1. 玩家能否一眼看出主要文本在哪里？
2. 玩家能否知道哪些东西可以点击？
3. 画面是否符合冷淡系统 + 夜间车站的方向？
4. 色彩是否统一？
5. 有没有不必要的装饰？
6. 是否服务于“系统正在观察玩家”这个主题？
