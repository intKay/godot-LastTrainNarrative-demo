# 《叙事校准程序 / 末班车站》v0.1 核心玩法设计

## 核心冲突

表层冲突：人 vs 系统。  
玩家面对一个冷淡、自动化、逐渐异常的叙事系统。

深层冲突：人 vs 故事本身。  
玩家以为自己在选择故事，故事却逐渐开始识别玩家的选择模式，并反过来限制、诱导或质问玩家。

## 主玩法循环

每一轮主玩法循环为：

1. 显示当前叙事文本
2. 玩家阅读车站状态
3. 玩家可以点击调查元素
4. 玩家从 3～4 个选项中选择一个
5. 游戏更新隐藏状态
6. 游戏更新车站元素
7. 进入下一轮

每次选择必须至少产生一种反馈：

- 文本反馈：广播语气、系统提示、叙事描述变化
- 场景反馈：公告牌、时钟、广播灯、出口门变化
- 线索反馈：玩家发现系统记录或异常
- 状态反馈：隐藏偏好变化
- 结局反馈：某类结局倾向增强

## 开场结构：叙事校准程序

玩家先进入“叙事校准程序”。

开场风格：

- 表面像故事生成器
- 视觉像冷淡的系统测试界面
- 不直接告诉玩家这是心理测试
- 三问用于记录初始偏好，并把玩家导入车站

三问功能：

1. 第一问：选择故事锚点
2. 第二问：选择主角最先注意到的细节
3. 第三问：选择故事偏离时主角保留的倾向

设计原则：

- 选项不应直白写出“怀疑、控制、顺从”等标签
- 选项表面应像故事选择，底层才记录状态
- 玩家不一定能真正选择不同场景，但系统应让玩家感觉选择影响了车站初始状态
- “末班车站”的出现应让玩家感到诧异但合理

## 主场景：末班车站

v0.1 不做复杂地图和小人移动。车站是一个极简 2D UI 场景。

主界面包含：

- 车站背景
- 公告牌
- 时钟
- 广播灯
- 出口门 / 闸机
- 主叙事文本框
- A/B/C/D 选项按钮

## 四个可点击调查元素

### 1. 公告牌

功能：系统信息与 meta 泄露。

承担：

- 车次信息
- 目的地
- 玩家选择残影
- 系统调试痕迹
- 叙事偏好记录

风险：

- 太早显示调试信息会过早暴露 meta
- 太隐晦则玩家看不懂

### 2. 时钟

功能：表现时间异常和叙事循环。

承担：

- 时间推进
- 时间停滞
- 时间倒退
- 时间变为无意义符号

风险：

- 互动性较弱，不应承担关键谜题
- 不要要求玩家必须点击时钟才能通关

### 3. 广播灯

功能：表示叙事系统 / AI 叙事者的状态。

承担：

- 系统稳定
- 广播迟疑
- 系统警觉
- 叙事者失真

风险：

- 不能只是装饰
- 也不要做成明显血条或压力条

### 4. 出口门 / 闸机

功能：目标感和终局压力源。

承担：

- 玩家是否能离开
- 离站许可是否生成
- 故事是否允许结束
- 终局选择入口

风险：

- 如果一直打不开，玩家会觉得被强行限制
- 每次点击都应提供新信息

## 车站五轮结构

五轮不是五个独立怪事，而是一条认知升级曲线。

### 第 1 轮：正常中带一点不对

目标：玩家知道这个车站和自己刚才的校准选择有关。  
异常：只出现一个轻微异常，例如公告牌出现玩家选择过的词。

### 第 2 轮：选择与异常发生对应

目标：玩家知道自己的选择会改变车站。  
异常：玩家选择质疑时广播停顿，选择离开时出口门回应，选择等待时时钟停住。

### 第 3 轮：系统开始归纳玩家

目标：玩家知道车站不只是变化，它在分类自己。  
异常：公告牌或广播出现冷淡系统标签，例如“重复选择：检查”“路径倾向：未确认”。

### 第 4 轮：玩家获得测试系统的机会

目标：玩家不再只是被动看异常，而是可以主动测试系统。  
选项方向：按广播提示等待、指出公告牌记录选择、尝试离开、不回应广播。

### 第 5 轮：终局选择

目标：玩家理解自己一直被系统观察，并做出最后选择。  
表现：系统通过冷淡 UI 显示校准完成、主要偏好、是否进入结局。

## 结局方向

### 怀疑结局

玩家识破车站是叙事测试空间，但系统指出“识破结构”本身也属于可预测行为。

### 控制结局

玩家利用系统规则生成出口或空白场景，似乎获得控制权，但也失去了故事本身。

### 顺从结局

玩家按照系统安排上车，故事顺利结束，但结尾暗示玩家从未真正偏离系统预期。
