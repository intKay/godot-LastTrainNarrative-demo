# 《叙事校准程序 / 末班车站》v0.1 开发任务清单

## 阶段 0：Godot 最小练习

目标：建立本项目所需的最低 Godot 心智模型。

任务：

1. 创建 Godot 4.x 项目
2. 创建一个 Control 根节点
3. 添加 Label 显示文本
4. 添加 4 个 Button 作为选项
5. 点击 Button 后更新 Label 文本
6. 添加变量 doubt，并在点击按钮时 doubt += 1
7. 添加一个“公告牌”按钮
8. 点击公告牌后显示调查文本
9. 添加一个简单结局界面
10. 点击某按钮后切换到结局界面

验收：

- 能运行
- 点击按钮有反馈
- 状态能变化
- 能切换界面

## 阶段 1：一分钟垂直切片

目标：验证核心体验。

任务：

1. 创建 calibration_screen.tscn
2. 实现一个校准问题
3. 创建 station_scene.tscn
4. 从校准界面切换到车站界面
5. 实现公告牌点击调查
6. 实现第一轮主线选项
7. 实现选项点击后的状态变化
8. 实现广播灯视觉变化
9. 实现公告牌显示选择残影
10. 加入最基础点击音效

验收：

- 玩家能完成 1 分钟流程
- 选择后至少一个车站元素变化
- 公告牌能体现玩家选择被记录
- 文本节奏不拖

## 阶段 2：完整 v0.1 流程

任务：

1. 补齐开场三问
2. 补齐车站五轮主线
3. 补齐公告牌、时钟、广播灯、出口门调查文本
4. 实现 GameState
5. 实现 MockAIManager
6. 实现 WorldStateController
7. 实现 EndingManager
8. 实现三个结局
9. 实现选择档案

验收：

- 能从开场玩到结局
- 至少三个结局可触发
- 每轮选择都有反馈
- 四个调查元素都可用

## 阶段 3：UI / 音效打磨

任务：

1. 统一字体
2. 统一颜色
3. 调整按钮间距
4. 增加按钮悬停效果
5. 增加广播灯闪烁
6. 增加公告牌刷新音
7. 增加低频环境音
8. 增加异常提示音
9. 加入可跳过打字机效果

验收：

- UI 不乱
- 文本易读
- 音效不吵
- 动效不拖节奏

## 阶段 4：试玩审计

任务：

1. 找 1～3 个玩家试玩
2. 观察玩家是否知道该做什么
3. 记录玩家在哪一刻意识到系统在观察自己
4. 记录玩家是否觉得选择有意义
5. 记录玩家是否觉得文本拖沓
6. 记录玩家是否愿意重玩
7. 根据反馈修改文本和节奏

## 优先级原则

优先做：

1. 选择反馈
2. 文本张力
3. 状态系统
4. 车站元素变化
5. 结局判断

暂时不做：

1. 真实 AI
2. 复杂美术
3. 自由输入
4. 角色移动
5. 多 NPC
6. 背包支线
7. 动态音乐
