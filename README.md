# 叙事校准程序 / 末班车站

**Godot 4.x 互动叙事游戏原型** — 玩家进入"叙事校准程序"系统，通过选择生成故事，最终抵达"末班车站"。你以为自己在选择故事走向，但系统正在记录、解释并利用你的选择偏好。

## 核心体验

玩家不是单纯阅读文本，而是在一个可见的叙事空间中做选择。每次选择都会影响文本、系统状态、车站元素或结局倾向。你逐渐意识到：这个系统不是在生成故事，而是在观察你如何选择故事。

## v0.1 功能

- 三个校准问题
- 一个末班车站主场景
- 三轮车站主线选择
- 四个调查元素（电子公告屏、时钟、广播灯、出口门）
- 简单状态系统（doubt / control / obedience / anomaly）
- 三个低保真结局（顺从、怀疑、控制）
- 基础视觉反馈（按钮禁用、广播灯变色、公告屏残影）

## 快速开始

### 运行需求

- [Godot 4.x](https://godotengine.org/)（推荐 4.6+）

### 运行方式

```bash
git clone git@github.com:intKay/godot-LastTrainNarrative-demo.git
cd godot-LastTrainNarrative-demo
# 用 Godot 打开 project.godot，按 F5 运行
```

入口场景：`scenes/calibration_screen.tscn`

## 技术栈

| 技术 | 用途 |
|------|------|
| Godot 4.6 | 游戏引擎 |
| GDScript | 游戏逻辑 |
| Control UI | 界面系统 |
| JSON | 数据驱动内容 |
| Jolt Physics | 3D 物理引擎 |

## 数据驱动管线

游戏内容（剧情文本、选项、结局等）以 JSON 格式存储在 `data/` 目录中，核心脚本从 JSON 加载数据，修改内容通常无需改动代码。
