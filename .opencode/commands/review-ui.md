---
description: 评审 stations_scene 的 UI 布局、设备视觉、动效、音效符合 v0.2 低保真冷淡风格
---

先读取 docs/101 §5（主交互高亮）、§7（入场与背景）、§8（设备按钮）、§9（音效）、docs/102 §10-13。

然后加载 `scenes/station_scene.tscn` 和 `scripts/station_scene.gd`。

逐项检查：

## UI 布局
1. 四个设备是否横向排列：[电子公告屏] [时钟] [广播灯] [出口门]？
2. 公告屏是否与时钟区分明显（板式 vs 方框）？
3. 玩家一眼知道哪里是主文本、哪里是选项、哪些设备可点击？
4. ObjectiveLabel 是否存在？文本是否正确对应 phase？

## 设备视觉
5. 时钟：方框数字时钟，显示 23:47，数码感？
6. 广播灯：圆形灯点 + 标签？hover/pressed 有反馈？
7. 出口门：看出双开门意象？门缝可亮起？
8. 所有设备按钮 hover / pressed / disabled 有基础视觉反馈？

## 背景与动效
9. 背景是否低保真几何风格（无复杂插画/写实/高饱和霓虹）？
10. 背景是否不抢主文本、不伪装成交互物？
11. 入场动画是否可以跳过（点击或空格）？
12. 动效是否不拖慢重玩（≤1.8s 或可跳过）？

## 音效
13. 是否有 4 种声音占位或实现？（ambient / notice_refresh / choice_commit / device_signal）
14. 音量是否低、不干扰阅读？
15. 是否引入旋律 BGM / 动态音乐 / 惊吓音？

## 代码检查
16. 可点击元素是否全用 Button，不用 Label 伪装？
17. 节点路径 `$RootMargin/VBox/...` 是否与 .tscn 实际结构一致？

## 输出格式

```
UI/音效评审报告

逐项评分（通过 / 需改进 / 需重做）：
  [序号] 问题描述 → 建议改进

违反约束：
  [序号] 违规点 → 引用 docs/102 对应条款

统计数据：
  通过 xx 项 / 需改进 xx 项 / 需重做 xx 项
```
