# Godot Narrative Slice

## 什么时候使用

当任务涉及《叙事校准程序 / 末班车站》的 Godot 4.x 一分钟垂直切片时使用本 skill，包括：

- 创建或修改校准界面
- 创建或修改末班车站界面
- 处理玩家选择和状态变化
- 处理公告牌调查文本
- 记录 `calibration_hint` 或 `last_choice_text`
- 审查功能是否超出切片范围

如果任务目标是完整 v0.1、真实 AI、完整结局、复杂美术或复杂音频，应先要求收窄范围。

## Godot 技术边界

- 使用 Godot 4.x。
- 使用 GDScript。
- 使用 Control UI 为主。
- 允许使用 `Label`、`Button`、`Panel`、`ColorRect`、`VBoxContainer`、`HBoxContainer` 等基础 UI 节点。
- 可使用 MockAI 或硬编码临时文本验证流程。
- 当前阶段不要求完整 JSON 内容管线。
- 当前阶段不接真实 AI API。
- 当前阶段不做复杂 2D 移动、物理、碰撞、3D、Shader、插件或多线程。

节点命名要稳定。需要点击的选项必须是 `Button`，不要误用 `Label`。主线按钮点击后必须禁用，避免重复刷状态。公告牌调查只显示文本或设置 flag，不直接修改四种核心状态值。

## 文案风格

文本要短、冷、准、有信息量，体现“系统正在观察玩家选择”的感觉。

优先写：

- 选择被记录
- 车站因选择出现轻微变化
- 系统用克制的方式反馈玩家行为
- 公告牌、广播灯、时钟、出口门等物件承载反馈

避免写：

- 长篇散文
- 纯氛围描写
- 过早说明真相
- 恐吓式惊吓
- 无反馈选择
- 复杂世界观解释

## 禁止扩展项

当前切片禁止：

- 完整三轮校准
- 完整五轮车站
- 结局系统
- 真实 AI API
- 自由文本输入
- 多 NPC 系统
- 战斗
- 背包
- 复杂谜题
- 复杂美术
- 复杂音频
- 未经确认修改 `project.godot` Autoload
- 一次性重构整个项目
